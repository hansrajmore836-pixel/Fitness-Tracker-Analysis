# Fitness Tracker Analysis 📊

## Project Overview
This project analyzes fitness tracker data using Python to understand daily physical activity, sleep patterns, calories burned, and weight trends.

## Objectives
- Analyze daily steps and calories burned.
- Study sleep patterns.
- Analyze weight trends.
- Compare weekdays and weekends.
- Identify relationships between fitness variables.
- Evaluate the 10,000 daily steps goal.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- Fitness_Tracker_Analysis.ipynb
- fitness_tracker.csv

## Analysis Performed
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Weekday vs Weekend Analysis
5. Weight Trend Analysis
6. Correlation Heatmap
7. Fitness Goal Analysis
